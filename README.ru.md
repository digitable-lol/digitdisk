# digitdisk — куда ушло место и как себя чувствует машина, только чтение

digitdisk печатает две картины машины и ничего при этом не меняет: **куда ушло
место на диске** — каталоги по размеру и самые крупные файлы — и **как машина
чувствует себя прямо сейчас** — процессор, память, диск, сеть. Читает,
печатает, выходит. Режима очистки нет, деинсталлятора нет, ключа, который
удаляет файл, нет.

## Из чего состоит

```
core/     показатели как спецификация на flang и напечатанный из неё Go в core/out-go
host/     хозяин на Go: системные вызовы, командная строка, вывод
tools/    лицензионный сторож
docs/     заметки, которым не место на этой странице
```

Разделение и есть всё устройство. Всё, что решается без обращения к
операционной системе, решается в `core/`: спецификация на flang, проверяемая
прогонами самого flang и **печатаемая** в Go. Всё, что без операционной системы
не решается, — обход каталогов, `statfs`, чтение счётчиков — рукописный Go в
`host/`. Ядро не открывает файлов; хозяин не решает, что значит число.

`core/out-go` печатается, а не пишется. Правка руками теряется при следующей
печати — см. [`AGENTS.md`](AGENTS.md).

## Сборка

Для сборки из чистого клона хватает Go: напечатанный Go лежит в дереве. Чтобы
перепечатать ядро, дополнительно нужен
[flang](https://github.com/digitable-lol/flang).

```bash
flang emit core/<модуль>.flang --target go --out core/out-go   # только когда изменилась спецификация
go build -o digitdisk ./host
```

## Запуск

```bash
./digitdisk disk [путь]    # куда ушло место: каталоги по размеру, самые крупные файлы
./digitdisk status         # как себя чувствует машина: процессор, память, диск, сеть
```

Обе команды читают. Ни одна не пишет.

## Чего не делает

- **Ничего не удаляет.** Ни очистки, ни деинсталляции, ни `--force`, ни
  каталога карантина. digitdisk печатает найденное; что убрать — решение
  читателя и команда кого-то другого. Патч, добавляющий путь удаления, — вне
  области задачи, а не заявка на возможность.
- **macOS не поддерживается.** Хозяин говорит с Linux и BSD. macOS не цель
  сборки, не цель прогона и не отчёт об ошибке, по которому мы можем что-то
  сделать.
- **Это не форк mole**, и кода mole под GPL-3.0 здесь нет — оттуда пришла
  идея, а не код. См. [`NOTICE`](NOTICE).
